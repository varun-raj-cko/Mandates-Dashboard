How to host this dashboard

This is a fully self-contained HTML file — no build step, no dependencies, no server needed. Host it anywhere that serves static files.

1
GitHub Pages (free, 2 min)
Create a repo, upload this file as index.html, then Settings → Pages → Deploy from main. URL: https://yourorg.github.io/repo-name
2
Netlify Drop (free, 30 sec)
Go to netlify.com/drop and drag this file onto the page. Instant live URL.
3
Company intranet / Confluence embed
Upload to your internal file server or embed in Confluence as an HTML macro. Works behind VPN.

AI chatbot setup

Each user needs to enter their own Anthropic API key in the AI Search page. Keys are stored in sessionStorage — they're cleared when the browser tab closes. To avoid per-user key entry, your team can set up a lightweight backend proxy that injects the key server-side.

Wiring up live Slack data

The refresh button simulates the Slack read. To make it live, add a small backend proxy (~50 lines Node/Python) that: reads new messages from #cp_fp_business-release, parses canvas attachments, and returns structured JSON. The Claude conversation that built this has all canvas and channel IDs as context.
